## 2. 后端待办：等决定

- **图片：带图动态、相册云同步**。要先定两件事：
  1. 公开图片怎么审核。建议内测先由运营在管理后台人工审核，以后接自动审核。
  2. 存在哪里。用 Supabase Storage 的私有存储，需要在 Fly 上加 Supabase 的服务端密钥。

  已对齐的要求：
  - 上传用签名 URL，限定类型、大小和路径；读图按条目鉴权。
  - 动态的附件要说明最多几张、格式和大小上限、顺序、alt 文本、审核状态、删除和孤立附件清理。
  - 相册按 `ownerId + clientItemId` 去重，由服务端生成 `remoteId`；要定游标、`revision / deletedAt`，以及先传附件还是先建条目。
  - 云同步要有用户主动开启的流程。原聊天消息删除后，用户主动保存的金句副本怎么处理，也要定下来。
- **打开自带 Key 和接自己的 Agent**：在 Fly 上设置 `CONNECTION_SECRET_KEY` 即可。
- **平台模型**：每日花费上限已经做好（默认每天 20 美元，管理后台可改）。上线前在 Fly 上放平台的模型密钥即可。在那之前，线上的家机回复和日记都会显示"即将开放"，`/v0/chat-models` 里的每一项都是不可用。
- **积分钱包的规则**：现在是关的。打开前要定：新人送多少（占位 1000 积分 = 1 美元模型成本）、1 分钱成本换多少积分（占位 10）、写日记给聊天留多少（占位 200）。都能在管理后台改。
- **内购充值**：钱包流水已经预留了 PURCHASE / REFUND（按商店交易号只记一次），还差服务端验单和商品定义。
