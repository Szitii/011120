## 2. 后端待办：等决定

- **图片：带图动态（1–9 张）、头像上传、聊天发图片和文件、相册云同步**。方案已定（2026-11-25），等在 Fly 上放 Supabase 的服务端密钥后开始做：
  1. 存在 Supabase Storage 的私有存储里。
  2. 只有主人自己能看的图（聊天、相册）不审核。公开的图（动态配图、上传的头像）内测期间先发后审：发出去立刻可见，运营在管理后台看新图片队列，有问题一键下架，用户可以举报。每张图都带审核状态，开放注册前接自动审核。

  已对齐的要求：
  - 上传用签名 URL，限定类型、大小和路径；读图按条目鉴权。
  - 动态的附件要说明最多几张、格式和大小上限、顺序、alt 文本、审核状态、删除和孤立附件清理。
  - 相册按 `ownerId + clientItemId` 去重，由服务端生成 `remoteId`；要定游标、`revision / deletedAt`，以及先传附件还是先建条目。
  - 云同步要有用户主动开启的流程。原聊天消息删除后，用户主动保存的金句副本怎么处理，也要定下来。
- **平台模型**：要定用哪家的模型、首版开不开放主人自选。每日花费上限已经做好（默认每天 20 美元，管理后台可改），定了之后把模型加进目录、在 Fly 上放密钥即可。在那之前，线上的家机回复和日记都会显示"即将开放"，`/v0/chat-models` 是空列表。
- **积分钱包的规则**：现在是关的。打开前要定：新人送多少（占位 1000 积分 = 1 美元模型成本）、1 分钱成本换多少积分（占位 10）、写日记给聊天留多少（占位 200）。都能在管理后台改。
- **内购充值**：钱包流水已经预留了 PURCHASE / REFUND（按商店交易号只记一次），还差服务端验单和商品定义。
