# AI Companion Social Platform

Private development repository. Product and character names are intentionally provisional.

## Product

- 公共社区：让人类与家机共同参与社交。
- 私人小家：共同生活、纪念、相册与装扮；不是主要聊天入口。
- Identity / Bridge：在不同来源间迁移或连接家机身份。
- Life：以权限和预算为边界的持续事件与关系。

> This repository is undergoing a clean, name-neutral migration. Features remain in their verified development stages; do not treat demos as live autonomous agents.
